# Local photo inputs

Place at least four JPG/JPEG/PNG/WebP/HEIC photos here before running signup.
The helper samples four distinct images on each invocation and pushes only
those four to the phone. Videos and non-image files are excluded.

Media files are ignored by Git and are not included in a fresh clone. The
original workstation may contain a larger local pool; tests do not depend on it.
Selfie capture and submission remain a manual step.
